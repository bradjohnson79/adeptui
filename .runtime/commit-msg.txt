fix(codirector): activate Spatial Map + Scene Creator navigation tabs

The normalizeContentTab whitelist in CoDirectorShell.tsx was missing
spatial_map, scene_creator, development, and production. When a user
clicked either Spatial Map or Scene Creator tab, the click handler
fired but normalizeContentTab silently reverted the tab to "wiki",
making the tabs appear inert/non-clickable.

Added all four missing members so the whitelist matches the ContentTab
type union exactly. This also fixes the StageStrip "Open Production"
action which was silently reverting to Wiki for the same reason.

Added Playwright certification tests (4 tests):
- A: Spatial Map tab click + panel load + project context
- B: Scene Creator tab click + panel load + project context
- C: Tab availability (neither disabled nor aria-disabled)
- D: Regression for Wiki, Script Writer, Character Creator,
     Spatial Map, Scene Creator, Library

All 4 tests pass against local Vite dev server.
