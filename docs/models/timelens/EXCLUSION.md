# TimeLens — excluded from Adept UI

Reviewed on `2026-08-20`.

TimeLens (TencentARC) is **not** a Setup component, optional toggle, hidden worker, or future default.

## Why

The TimeLens LICENSE is a custom academic-only grant:

- Use is limited to academic purposes.
- Commercial and production use are forbidden.
- The software is not intended for use within the European Union.

Those terms are incompatible with Adept UI as a commercial product.

## Rule

Do not download, bundle, wrap, or silently call TimeLens. VideoChat3 + InternVideo3 cover Revision A temporal review. Precise event timestamps remain unknown when the local stack cannot ground them — never invent them.
