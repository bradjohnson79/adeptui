# M3.1a — Templates/Presets Foundation + Project Types

**Status:** Implemented (foundation slice)  
**Flag:** `STUDIO_FEATURE_TEMPLATES_PRESETS_V1`

## What shipped

- Unified Templates & Presets package at `studio-api/app/templates_presets/`
- Migration `m020` (`0020`): `creative_items`, versions, bindings, `project_type_definitions`, `production_units`, project/scene columns, legacy production-type backfill
- Built-in Project Type catalog (including **Video / Cinematic Trailer**) with resolved Project Profiles
- End-to-end project create / preview / apply / custom-type save
- Intent + `providerMappings` separation on all creative items
- Project Library virtual taxonomy: **Templates and Presets** (`librarySchemaVersion` → 2)
- Read-only adapters for M2.8 shot profiles, M2.13 lighting/theme, and `profile_items`
- Co-Director `project_profile` includes primary type, traits, and resolved profile summary
- New-project UX primary selector + traits; Project Settings type change preview/apply

## Explicit exclusions (follow-up slices)

Full generation/camera/lighting/color/look catalogs and execution (M3.1b–f), Co-Director NL intelligence (M3.1g), Bible conflict detection (M3.1h), full certification/native gen (M3.1i), marketplace sharing, and full migration of M2.8/M2.13/`profile_items`.
