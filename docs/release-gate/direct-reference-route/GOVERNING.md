# Adept Direct Reference Route — Governing

This is the single current authority for Timeline reference transport.

Supersedes any prior assumption that Co-Director, prompt compile, `characterIdentity` leftovers, voice bind, or sheet crops may decide who is in a generation.

## Law

What the creator checks in Timeline References is exactly what Comfy receives.

`@` character, `#` environment, `%` prop, `*` motion. Canonical tags do not change (`@Korri40YearsOld`, `@Addex`).

## Route

```
References UI (checked bindings)
  → Canonical Reference Registry (DirectReferencePayload)
  → Direct Reference Transport (validate + copy original file)
  → Generator Adapter (socket map only)
  → Exact Comfy reference sockets
```

No other subsystem may add, replace, drop, or reinterpret a reference once this route is authoritative.

## Not authority

Co-Director, Timed Prompt prose, previous batches/scenes, `characterIdentity` / `characterVoice` rows, approved-voice auto-bind, first-frame substitution, H3 identity still crops, asset inference, automatic cast completion.

Co-Director may *read* the payload for planning. It may not write it.

## Payloads stay separate

- **Reference payload:** who/what is visually (or auditorily) referenced.
- **Prompt payload:** what happens (style, action, dialogue, camera).

They meet only at the generator adapter. Neither rewrites the other.

## Failure

If a checked reference cannot be delivered to a real generator socket, generation is blocked. No silent drop, substitute, or extra cast.

## This mission

Prove **transport**. Identity fidelity of MiniMax itself is out of scope.
