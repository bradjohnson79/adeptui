# Movement Segment Full Production System — Governing Document

One Spatial Map document is the only Movement authority.

```text
SPATIAL MAP     = physical scene truth
MOVEMENT SEGMENT = what is true at this moment (M1–M5)
ERS             = visual index (frozen 3×3 + code-assembled strip)
SCENE CREATOR   = M + C coverage
TIMELINE        = structured ~M tags + durations
CO-DIRECTOR     = planner over the same JSON
```

## Inheritance law

State-based, not prompt-based. Creating M2 copies placements, props,
attachments, facing, visibility, continuity, and camera refs. Direction and
dialogue start blank unless supplied for that beat.

```text
M1 = state A
M2 = state B
M1 → M2 = derived transition
```

Generators receive separate layers: unchanged facts, starting state, ending
state, action/direction, Timed Prompt. They must not collapse to a single
walk sentence.

## Surfaces

- Express and Standard Spatial Map share `SpatialMapPanel`.
- Scene Creator Express remains a launcher. Movement lives on Mini and Standard.
- Cameras stay global. Mini hero crop stays panel 0 of the **core** 16:9 sheet.
