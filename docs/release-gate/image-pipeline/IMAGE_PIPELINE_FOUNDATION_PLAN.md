# Image Pipeline Foundation Plan

Short mirror of the implemented foundation scope.

## Included

- Frozen Pydantic contracts for planning, routing, candidates, repair, mastering, and provenance.
- Deterministic shot intelligence and creative direction helpers.
- Staging recommendation for `poseCraft`, `spatialMap`, or direct generation.
- Filesystem persistence under `data/image_pipeline/{project_id}/`.
- Honest candidate generation path that either enqueues real downstream jobs or records draft slots without false success.
- FastAPI router under `/api/image-pipeline`.
- Unit coverage for the deterministic foundation behavior.

## Not included

- New image runtime engines.
- Automatic paid API execution without approval.
- Vision-model quality judging. Foundation validation remains metadata- and readiness-based unless real image analysis is added later.
