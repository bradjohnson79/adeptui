## Purpose

Provide a frozen inventory of native capabilities that M2.10 Capability Expansion compares against to determine whether an add-on:

- **fills missing** native gaps (e.g. generative Audio/SFX/Music deferred from M2.9)
- **improves** an existing native capability
- **duplicates** an existing native capability (usually reject or require explicit override proposal)
- should be **rejected**
