# M2.10 Native Capability Snapshot

**Status:** **spec / template — freeze after READY FOR M2.10 re-audit**  
**Do not claim this snapshot is frozen yet.**  
**Discovery must not begin until this snapshot is frozen** (plus readiness READY + Product authorization).

## Purpose

Provide a frozen inventory of native capabilities that M2.10 Capability Expansion compares against to determine whether an add-on:

- **fills missing** native gaps (e.g. generative Audio/SFX/Music deferred from M2.9)
- **improves** an existing native capability
- **duplicates** an existing native capability (usually reject or require explicit override proposal)
- should be **rejected**

## When to freeze

Sequence:

1. M2.9 Accepted with limitations — **done** ([M2.9_ACCEPTED_WITH_LIMITATIONS.md](./M2.9_ACCEPTED_WITH_LIMITATIONS.md))
2. Readiness re-audit → READY FOR M2.10 — **recommended next; not executed in disposition pass**
3. **Native Capability Snapshot frozen** — this deliverable
4. Product authorizes M2.10
5. Discovery may begin

## Required fields (every capability record)

| Field | Description |
| --- | --- |
| Capability ID | Stable PRS ID |
| Native provider | Provider ID(s) that satisfy the capability |
| Version | Capability / adapter / provider version string |
| Supported models | Model IDs or workflow adapters declared for the capability |
| Job handler | M2.7 / studio Job handler ID(s) |
| Validation owner | Who owns validation (e.g. M2.5 vision, workflow validator) |
| Approval owner | Who owns approval gate (proposal bus, sandbox promote, etc.) |
| Status | `CONNECTED` or `PARTIAL` (honest; never fake CONNECTED) |
| Performance metrics | Optional |
| Feature flag | Gating flag name |
| Source | Always `native` for this snapshot |

## Process to produce the frozen snapshot

1. Start from `adept-ui-v1.0-native.json` + live registry honesty + M2.9 section acceptance matrix.
2. Map each capability into the snapshot schema fields above.
3. Mark status CONNECTED or PARTIAL honestly (generative audio generate paths remain PARTIAL / not CONNECTED until expanded in M2.10).
4. After readiness re-audit yields READY FOR M2.10, Product approves freeze.
5. Write frozen file (recommended name: `config/capabilities/adept-ui-v1.0-native-snapshot.frozen.json`) + sha256; update this doc status to **frozen** with tip SHA/date.
6. Only then authorize discovery.
