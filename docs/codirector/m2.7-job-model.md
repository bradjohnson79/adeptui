# M2.7 Job Model

## Tables (M008)

- `production_jobs` — durable job rows (type, owner, project/scene/timeline refs, priority, status, capability JSON, payload/result, idempotency key, attempts)
- `production_job_attempts` — append-only attempt history (never overwritten)
- `production_job_dependencies` — DAG edges
- `production_job_events` — typed persisted events
- `production_notifications` — user-facing notices derived from events
- `production_job_audit` — immutable status transitions

## Statuses

Queued, Waiting, Running, Paused, Blocked, Retrying, Cancelled, Completed, Failed, NeedsReview

## Idempotency

`create` with `idempotencyKey` returns the existing job for `(project_id, key)`.

## Scene progress

Derived from job statuses for a scene — never manually edited on the Executive dashboard.
