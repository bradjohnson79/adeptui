## Purpose

Freeze the authoritative inventory of **providers, workflows, processors, validators, and missing slots** actually present in Adept UI v1.0 native project state — for M2.10.1 discovery comparison and M2.10b Gate 4.

This manifest is derived from real registries; it does **not** invent generative providers for deferred audio gaps.
