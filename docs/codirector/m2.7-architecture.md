## Role

Production Executive is an **orchestration layer only**. It schedules, queues, pauses, retries, and notifies. It does **not**:

- Rebuild Bible / Proposal Bus / Timeline / Refs / Vision / Capability Bridge / Provider Registry / Director / Scene / Assets
- Auto-approve anything
- Silently mutate Production Bible canon
- Silently regenerate assets
- Bypass M2.2 Proposal → Review → Approval

## Status machine

`Queued → Waiting → Running → (Paused|Blocked|Retrying|NeedsReview|Completed|Failed|Cancelled)`

Crash recovery: `Running` → `Retrying` with open attempt closed as `interrupted` (append-only history).

## Closed loop (real-wired in M2.7.1)

`storyboard_generate → image_generate → validate → create_proposal → await_approval → apply_canon`

`await_approval` stops at `NeedsReview` until `POST .../mark-approval` (external M2.2 signal). `apply_canon` uses `ProposalService.approve` after explicit approval and **never** silently writes canon.
