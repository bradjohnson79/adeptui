# M2.9 Accepted With Limitations

**Acceptance date:** 2026-07-26  
**Branch:** `phase2/codirector-m2-9-production-suite`  
**Tip SHA (at disposition docs authoring):** `ceace572205efebe39e192c4f827f9676b597e79` (`ceace57`) — update after commit if needed.

**Product disposition (authoritative):** M2.9 is **ACCEPTED** with documented limitations — **not** blocked forever by missing generative Audio / SFX / Music.

## Redefined Definition of Done

> Every production department must be fully wired to every currently available native capability.

**Not** the DoD: every department must contain every possible generator.

## Limitations (deferred to M2.10)

| Capability | Status | Deferred to |
| --- | --- | --- |
| Native Generative Audio (dialogue / TTS / ambience / foley generate) | FIXTURE_ONLY / unavailable — not CONNECTED | M2.10 Capability Expansion |
| Native Generative SFX (generate) | PARTIAL — placement CONNECTED; generate unavailable | M2.10 Capability Expansion |
| Native Generative Music (generate) | PARTIAL — placement/ducking CONNECTED; generate unavailable | M2.10 Capability Expansion |

**Rationale:** Forcing new generative audio providers into M2.9 would absorb M2.10 scope and blur milestones. M2.10 exists to expand beyond native capabilities.

## What IS accepted

- **9 CONNECTED departments / wires:** Image, Frame, Video, Director Timeline, Lip Sync, Mouth Rect/Track, Editing, Rendering, Co-Director Control
- **Audio process** CONNECTED via ffmpeg loudnorm/cleanup (`media_ops.run_ffmpeg`)
- **SFX / Music placement** (and music ducking metadata) wired where native paths exist
- Honest classifications retained: generative generate paths remain PARTIAL / FIXTURE_ONLY — **not** faked as CONNECTED

See [m2.9-section-acceptance.md](./m2.9-section-acceptance.md) and [M2.9_FINAL_ACCEPTANCE_REPORT.md](./M2.9_FINAL_ACCEPTANCE_REPORT.md).
