M2.10b is **not** a discovery campaign. Do not perform broad GitHub or Hugging Face searches, expand the candidate list, install unapproved candidates, or modify the production environment during initial qualification.

## Core principle

M2.10 discovers and qualifies what may be valuable.
M2.10b safely installs, tests, integrates, and promotes only what proves production value.
M3.0 then proves the frozen Adept UI v1.1 filmmaking platform works as one complete system.

## Final verdict rules

Use exactly one:
ACCEPTED
CONDITIONALLY ACCEPTED
NOT ACCEPTED
Do not mark ACCEPTED if:
- A promoted candidate lacks exact provenance
- A promoted candidate lacks license clearance
- A promoted candidate bypasses M2.7
- A promoted visual capability bypasses M2.5
- A promoted capability lacks persistence or lineage
- A promoted candidate lacks rollback
- Production installation is unverified
- Critical integration failures remain
- The v1.1 registry is incomplete
A sandbox-qualified candidate does not need to be promoted.
A rejected candidate does not fail the milestone if the rejection is honest, evidenced, and safely handled.
M2.10b succeeds by selecting and integrating the right add-ons—not by maximizing the number installed.
