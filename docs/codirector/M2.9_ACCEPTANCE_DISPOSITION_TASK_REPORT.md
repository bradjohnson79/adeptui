## Executive summary

Product redefined the M2.9 Definition of Done and signed off the milestone as **ACCEPTED with documented limitations**. Missing native generative Audio / SFX / Music **generate** paths are deferred to **M2.10 Capability Expansion** and are **not** eternal blockers for M2.9. M2.10 was reframed as a disciplined discovery→promotion pipeline beyond native capabilities. This disposition pass did **not** run readiness re-audit, did **not** start discovery, and did **not** claim READY FOR M2.10.

---

## Redefined acceptance criterion

> Every production department must be fully wired to every currently available native capability.

**Not** the DoD: every department must contain every possible generator.

---

## Limitations deferred to M2.10

| Capability | Status | Deferred to |
| --- | --- | --- |
| Native Generative Audio (dialogue / TTS / ambience / foley generate) | FIXTURE_ONLY / unavailable — not CONNECTED | M2.10 Capability Expansion |
| Native Generative SFX (generate) | PARTIAL — placement CONNECTED; generate unavailable | M2.10 Capability Expansion |
| Native Generative Music (generate) | PARTIAL — placement/ducking CONNECTED; generate unavailable | M2.10 Capability Expansion |

**Rationale:** Forcing new generative audio providers into M2.9 would absorb M2.10 scope and blur milestones. M2.10 exists to expand beyond native capabilities.

## M2.10 reframing (Capability Expansion pipeline)

M2.10 is **Capability Expansion**: Adept UI grows **beyond its native capabilities** via a disciplined pipeline:

```text
Discover → Evaluate → Sandbox → Integrate → Promote → Feature Freeze
```

| Milestone | Role |
| --- | --- |
| **M2.8** | Builds the Model Radar, compatibility intelligence, sandboxing, routing, approval, and promotion architecture. |
| **M2.9** | Completes the native production platform (wired to available native capabilities; Accepted with documented limitations). |
| **M2.10** | Capability Expansion — Discover → Evaluate → Sandbox → Integrate → Promote → Feature Freeze. |
| **M3.0** | Proves frozen v1.1 end to end through full qualification. |

**Status:** Planning only — **not started**. Awaiting readiness re-audit + Native Capability Snapshot freeze + Product authorization. Discovery, GitHub/HF scanning, downloads, installs, sandbox execution, integration, and promotion are **not authorized** until those hard prerequisites are met.

Principle:

```text
M2.9 completes the native platform (wired to available native capabilities).
M2.10 expands beyond native via disciplined discovery→promotion.
M3.0 proves frozen v1.1 end to end.
```
