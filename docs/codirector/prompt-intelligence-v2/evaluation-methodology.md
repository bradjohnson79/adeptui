# Evaluation Methodology

## Automated (technical health only)

- Job completed successfully
- Artifact exists and is non-empty
- Dimensions / duration / format match controls
- Video: black-frame / frozen-frame heuristics
- Audio: clipping / silence heuristics
- Metadata completeness

Automated checks **never** certify creative quality.

## Human blind review

- Strategy labels hidden until submit
- Side-by-side / sync playback
- Scores 0–100 per criterion
- Preferred / tie / fail flags

## Aggregation

Mean human score per strategy; confidence from sample count + score spread. Promotion requires ≥3 successful outputs per strategy per case.
