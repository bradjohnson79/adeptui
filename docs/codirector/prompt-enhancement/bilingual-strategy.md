# Bilingual Strategy (Selective Chinese)

Bilingual prompting is **not** generic translation.

- English remains the structural prompt.
- Chinese adds concise semantic clauses derived from intent (micro-expression, lighting, camera motion, etc.).
- Balance: Subtle (≤2 clauses), Balanced (≤4), Strong (≤7, advanced/experimental).
- Default global: Chinese **Off**.
- Negatives stay separate and are never folded into the Chinese layer.
