# Prompt Intelligence Architecture

Product name: **Prompt Intelligence** (bilingual English + Chinese is v1 of Language Modules).

```text
Creator Prompt
    → Terminology protect
    → Intent analysis
    → Prompt Quality Analyzer
    → Refinement modules (production, cinematic, motion, audio, continuity, provider)
    → Language modules (en structural, zh selective, ja/ko/fr future)
    → Compose + validate
    → Final Provider Prompt
```

Deterministic-first; optional Ollama polish is not required for v1. Local-only remains local. Chinese is never silently enabled from a provider recommendation.
