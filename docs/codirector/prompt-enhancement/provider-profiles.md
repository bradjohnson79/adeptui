# Provider + Model + Version Prompt Profiles

Profiles live under `config/codirector/prompt-profiles/` with an `index.json` alias map.

Examples:

- `ltx-video@1.0`
- `wan-2.2@1.1`
- `hunyuan-video-1.5@1.0`
- `hunyuan-video-13b@1.2`
- `minimax-h3@1.0` (disabled / Coming Soon)
- `flux-image@1.0`
- `audio-studio@1.0`
- `qwen3-tts@1.0`

`bilingualCertified` stays `false` until benchmark evidence is recorded. Recommendations may suggest Chinese; they do not auto-enable it.
