- `get_timeline_image`
- `list_timeline_images`
- `get_reference_set`
- `list_reference_bindings`
- `build_generation_reference_package`

- `propose_add_reference_binding`
- `propose_remove_reference_binding`

- `propose_apply_reference_preset`

## Capability bridge
