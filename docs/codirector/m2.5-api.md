# Co-Director M2.5 - Vision APIs

Flag: STUDIO_FEATURE_VISION_VALIDATION_V1 (default off). When off, routes return 404.

Mounted under /api/codirector/vision/* via routers/codirector.py.

- POST /validate
- GET /report/{id}
- GET /session/{id}
- POST /approve
- POST /reject
- POST /correction
- GET /comparison/{id}
- GET /history?projectId=

Tools: vision_validation_status, vision_validation_report (read); propose_vision_correction, propose_asset_bible_link, record_vision_review (mutate via proposals).

Capabilities: codirector.vision.validate, codirector.vision.review.
