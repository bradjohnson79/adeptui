# M2.6 — Timeline Reference Binding API

Flag: `STUDIO_FEATURE_TIMELINE_REFERENCES_V1` (default off). Disabled → 404.

## Item routes

Base: `/api/projects/{projectId}/scenes/{sceneId}/director/items/{itemId}`

| Method | Path | Notes |
|---|---|---|
| GET | `/references` | Active set + bindings + count |
| POST | `/references` | Add binding (COW) |
| PATCH | `/references/{bindingId}` | Update binding (COW) |
| DELETE | `/references/{bindingId}` | Remove binding (COW) |
| POST | `/references/clear` | Empty set (COW) |
| POST | `/references/restore/{version}` | Restore prior version via new COW version |
| GET | `/reference-package` | Provider-neutral package |
| POST | `/reference-package/validate` | Capability/support check (not pixel validate) |
| POST | `/references/continuity-previous` | Nearest approved frame → continuity |
| POST | `/reference-presets/apply` | Apply project preset |

## Project presets

| Method | Path |
|---|---|
| GET | `/api/projects/{projectId}/reference-presets` |
| POST | `/api/projects/{projectId}/reference-presets` |

## Package shape

```json
{
  "primaryFrame": { "timelineItemId", "displayTag", "assetId", "role": "primary_frame" },
  "referenceSet": { "id", "version", "bindings": [...] } | null,
  "support": { "status": "ready|degraded", "unsupportedBindings": [...], "icLoraReady": false }
}
```

Empty refs → `referenceSet: null`. `blocksRun` is always false.
