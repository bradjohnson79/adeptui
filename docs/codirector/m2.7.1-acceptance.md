# M2.7.1 Acceptance Checklist

M2.7 is **accepted only when M2.7.1** criteria below pass. Map each scenario to pytest and/or Playwright coverage.

**Suites**

- Pytest: `studio-api/tests/test_production_executive.py` (run with `ADEPT_MOCK_IMAGEGEN=1` as tests set)
- Playwright: `tests/e2e/codirector/production-executive-m27.spec.ts`
- Related regression (recommended): M008 migrations, M2.5 vision, M2.6 refs / M2.6.1 closed-loop

## Checklist

| Scenario | Expectation | Pytest | Playwright |
|----------|-------------|--------|------------|
| **Flag off** | APIs 404; UI shows Off / dashboard hidden | `test_feature_flag_defaults_off`, `test_api_flag_off_404` | `flag off shows Off and hides dashboard` |
| **Closed-loop** | Real-wired chain runs; drains toward approval gate | `test_closed_loop_real_wiring_no_auto_approve`, `test_api_flag_on_create_and_inspect`, `test_chain_propagates_asset_and_proposal_ids`, `test_image_generate_uses_job_asset_lifecycle`, `test_contracts_validate_closed_loop_inputs` | `closed loop drains to NeedsReview`, `dashboard tabs visible after successful closed loop` |
| **NeedsReview** | `await_approval` stops until explicit signal | `test_await_approval_stays_needs_review_without_signal`, `test_closed_loop_real_wiring_no_auto_approve` | `closed loop drains to NeedsReview` |
| **Canon unchanged until approve** | No Bible mutation / proposal not approved before signal | `test_apply_canon_blocked_without_approval`, `test_closed_loop_real_wiring_no_auto_approve` | `canon unchanged until mark-approval` |
| **Approve** | `mark-approval` is external signal; `autoApproved: false` | `test_mark_approval_auto_approved_false_api` | `mark-approval returns autoApproved false` |
| **Bible receipt** | After approve + drain, `apply_canon` completes via `ProposalService.approve` with receipt | `test_closed_loop_real_wiring_no_auto_approve` (approve path) | `after approve and drain apply completes with receipt` |
| **Events / audit** | Persisted events + audit/history endpoints return data | Covered via closed-loop / API inspect tests; events store exercised in drain path | `events and audit history endpoints return data` |
| **Failure / retry** | Retry budget / status transitions honest | `test_provider_unavailable_blocks`, pause/retry portions of `test_pause_resume_retry_cancel` | `failure retry on generic job` |
| **Pause / resume** | Operator can pause and resume | `test_pause_resume_retry_cancel` | `pause and resume generic job` |
| **Cancel** | Cancel stops further side effects cooperatively | `test_pause_resume_retry_cancel` | `cancel generic job` |
| **Restart recovery** | `Running` recovered without duplicate attempts | `test_crash_restart_recovery_no_duplicate_attempts` | `restart recovery documented in pytest` (points to pytest; no fake multi-process claim) |
| **Idempotency** | Duplicate closed-loop create reuses / does not double-fire unsafely | `test_idempotency_duplicate_create` | `closed-loop idempotency reuses jobs` |
