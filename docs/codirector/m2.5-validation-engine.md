# Co-Director M2.5 - Validation Engine

## Purpose

Inspect generated (or mock) assets against Production Bible / generation-package requirements. Validators never auto-regenerate, auto-approve, or silently mutate the Bible.

## Package

`studio-api/app/codirector/vision/`

- engine.py: Orchestrator
- validators: identity, continuity, technical, lighting, camera, composition, color, motion
- providers: mock (deterministic) + local (OpenCV/Pillow; ML stubs inconclusive)
- reports.py: weighted score + bands; blocking fails cannot be averaged away
- store.py: SQL persistence; clears visualValidationPending

## Weights / thresholds

Identity 30, Continuity 25, Technical 20, Lighting 10, Camera 5, Composition 5, Color 5 (+ Motion for video).

Bands: >=95 approve; 90-94 review; 80-89 corrections required; <80 reject.

## Pending flag

M2.5 is the first code allowed to clear ProductionPlan.visualValidationPending when a session reaches terminal completed or failed.
