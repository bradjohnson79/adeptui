# M2.7 Events & Notifications

## Persisted events (`production_job_events`)

Examples: `job.created`, `job.status_changed`, `job.attempt_started`, `job.attempt_finished`, `job.completed`, `provider.unavailable`.

## In-process bus

`ProductionEventBus` publishes after persist; subscribers may listen for `*` or typed events.

## Notifications

Stored in `production_notifications`, separate from immutable `production_job_audit`. Levels: info / warn / error / success.

## Audit

Every status transition appends a `production_job_audit` row (`from_status`, `to_status`, `actor`, `reason`).
