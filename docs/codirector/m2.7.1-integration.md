# M2.7.1 Integration — Real Service Wiring

## Purpose

M2.7.1 connects the Production Executive closed-loop handlers to real Adept services (in-process). Orchestration remains the only Executive responsibility; Bible / Proposal / Timeline / Refs / Vision / Bridge / Registry are not rebuilt.

**Branch:** `phase2/codirector-m2-7-production-executive`  
**Flag:** `STUDIO_FEATURE_PRODUCTION_EXECUTIVE_V1` (default **OFF**)

---

## Typed contracts

`studio-api/app/codirector/executive/contracts.py`

- Per-`JobType` input/output Pydantic schemas
- Runtime defaults: validate provider `local`; image provider `comfy`; no default `fixtureProfile: pass`
- Boundary helpers: `validate_job_input` / `validate_job_output` / `audit_metadata`

---

## Handler wiring (closed loop)

`studio-api/app/codirector/executive/handlers.py` — **in-process SQLAlchemy `Session` only; no self-HTTP.**

| Job type | Real service path |
|----------|-------------------|
| `storyboard_generate` | `storyboard_jobs.prepare_storyboard_generate` + queue enqueue |
| `image_generate` | Real Job + Asset lifecycle via `imagegen_adapter.poll_imagegen_job` (**no mock substitute**) |
| `validate` | M2.5 `run_validation` with provider `local` (rejects `mock`) + optional refs remap |
| `create_proposal` | M2.2 `ProposalService.create_proposal` / `get` |
| `await_approval` | Polls proposal status; stays `NeedsReview` until approved or mark-approval |
| `apply_canon` | `ProposalService.approve` only after explicit approval |

### ImageGen adapter (democked)

`studio-api/app/codirector/executive/imagegen_adapter.py`

- Polls real studio Jobs only
- `should_use_mock_imagegen()` always returns `False`
- `ADEPT_MOCK_IMAGEGEN` / `STUDIO_E2E` do **not** enable silent Job+Asset completion
- If Comfy unavailable → clear `RuntimeError` / Failed|Blocked — never invented assets

### Production Context

Created once in `create_closed_loop`; see `m2.7.1-production-context.md`.

### Validation + refs

- `run_validation(db, ValidateRequest)` from `codirector.vision.engine`
- Optional `ReferencePackageBuilder` remap
- `visualValidationPendingCleared` true only when `planId` was set

### Proposals / canon

- Create/get via `ProposalService`
- Canon apply **only** via `ProposalService.approve` after explicit approval
- `mark-approval` adapter keeps `autoApproved: false`

---

## Result chaining

`worker._chain_results_to_dependents` propagates closed-loop outputs into dependent job payloads:

`panelId`, `imageJobId`, `assetId`, `proposalId`, `sessionId`, `reportId`, `score`, `passed`, `band`, `proposalApproved`

---

## Non-negotiables

- **Never silent approve** — `await_approval` stops at `NeedsReview`
- **Never silent canon** — no direct Bible mutation
- **Never silent mock ImageGen** — no invented assets on runtime path
- **`visualValidationPending`** cleared only by M2.5 VisionEngine when `planId` is set

---

## Feature flag / env

| Flag / env | Role |
|------------|------|
| `STUDIO_FEATURE_PRODUCTION_EXECUTIVE_V1` | Default OFF — APIs 404 / worker not started |
| `STUDIO_FEATURE_VISION_VALIDATION_V1` | Required for real validate path |
| `STUDIO_PRODUCTION_EXECUTIVE_POLL_INTERVAL` | Worker poll interval |
| `ADEPT_MOCK_IMAGEGEN` | **Must not** silently complete ImageGen on runtime path |
