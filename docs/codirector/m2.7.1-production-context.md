# M2.7.1 Production Context Contract

Immutable **Production Context** binds a closed-loop / job-graph run to a single sparse fact set created once at start.

## Lifecycle

1. `ProductionExecutiveService.create_closed_loop` calls `create_production_context` **once**.
2. The same `production_context_id` is stored on **every** job in the graph.
3. Each job payload embeds an immutable `productionContext` snapshot (`to_dict()`, Nones omitted).
4. The original context row / JSON is **never mutated**. Later facts use append-only `production_context_extensions` plus audit events (`production_context.extension`).

## Fields

| Field | Required | Notes |
|-------|----------|-------|
| `id` | yes (after persist) | Context row PK |
| `projectId` | yes | |
| `sceneId` | yes | |
| `createdAt` | yes | ISO timestamp |
| `initiatedBy` | optional | Owner / actor at create |
| `shotId`, `storyboardId`, `timelineId` | optional | Omit when unknown |
| `productionBibleVersion`, `referenceSetVersion` | optional | Omit when unknown |
| `cinematicDNA`, `workflowVersion`, `executionManifestId` | optional | Omit when unknown |

Do **not** invent placeholder values for sparse fields.
