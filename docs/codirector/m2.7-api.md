# M2.7 Production Executive API

Flag off → **404** (same pattern as vision/timeline).

Base: `/api/codirector/jobs`

| Method | Path | Purpose |
|--------|------|---------|
| POST | `/` | Create job |
| POST | `/closed-loop` | Queue mock storyboard→…→canon chain |
| GET | `/` | Queue list (`projectId`, optional `status`/`sceneId`) |
| GET | `/events` | Persisted events |
| GET | `/notifications` | Notifications |
| GET | `/statistics` | Counts by status/type |
| GET | `/scene-progress` | Derived scene progress |
| POST | `/worker/drain` | Sync drain (tests/ops) |
| GET | `/{id}` | Inspect |
| GET | `/{id}/dependencies` | Dep graph |
| GET | `/{id}/history` | Attempts + audit + events |
| POST | `/{id}/pause` | Pause |
| POST | `/{id}/resume` | Resume |
| POST | `/{id}/retry` | Retry |
| POST | `/{id}/cancel` | Cancel |
| POST | `/{id}/mark-approval` | External M2.2 approval signal (`autoApproved: false`) |

Health exposes `operator.productionExecutiveEnabled` and provider health `productionExecutiveEnabled`.
