### C2 update - live fal proof ran (2026-07-27)

A single budgeted live job was submitted with the key now present in the repo `.env`: engine
`fal_seedance`, endpoint `bytedance/seedance-2.0/text-to-video`, 4 s at 480p, no audio. fal
returned request id `019fa1fc-e05f-7d80-9908-e6d0c3e8d4fc` and a playable 668 KB MP4, saved
to `artifacts/m30a-fal/seedance_t2v_4s_480p.mp4`. One job only; the paid path is no longer
theoretical.

Still open on C2: the **image-to-video** endpoint (needs a start image), live failure
recovery, and the queue-worker job-row / Asset write-back, which this proof bypassed by
calling the same render helpers directly. Cost could not be read back because usage and
billing need an ADMIN-scoped fal key. Details: [FAL_AI_REAL_JOB_RESULTS.md](./m3.0a/FAL_AI_REAL_JOB_RESULTS.md).
