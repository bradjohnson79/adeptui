## 2. Product decision (locked)

Adept UI Studio is **local-first**:

1. Installed local open-source provider  
2. User-selected local model  
3. Compatible alternate local model already known to the registry  
4. fal.ai only with **explicit** paid approval — never silent  

Hierarchy before paid fal:

```text
preferred local still → alternate compatible local still
→ preferred local I2V (LTX 2.3) → alternate compatible local I2V
→ explicit paid fal dialog
```

Z-Image is **not** mandatory for certification: if another supported local ImageGen engine is the ready production path, that actual model is recorded instead. On this host Z-Image was GREEN and used.

## 4. Certified generation path (two-stage)

LTX in this codebase is **image-to-video**, not fal-style text-to-video. The certified chain is:

```text
Local ImageGen still (Z-Image)
→ register / hash start-frame asset
→ bind as scene start_frame
→ Studio render_scene engine=ltx
→ ComfyUI LTX 2.3 I2V (LTXVImgToVideo + LTXAVTextEncoderLoader)
→ product export pack
```

Do not describe the whole result as “LTX-only generation.” Provenance records both stages:

| Stage | Provider | Model |
|-------|----------|-------|
| Start frame | `comfyui` | `zimage` |
| Video | `comfyui` | `ltx-2.3` |
