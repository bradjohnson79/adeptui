## 1. Spatial Map + Atlas Shot + ERS + Scene Creator Implementation

### Objective
Implement a four-part spatial-continuity and scene-generation workflow integrated into the Co-Director Project Building experience, using mandatory subagents for architecture audit, data contracts, UI, generation, entity tagging, Library/Timeline integration, Co-Director integration, Playwright, and independent verification.

### Workflow (frozen, amended)
```
Story -> Script Writer -> Character Creator -> Atlas Shot / Master Environment
    -> Spatial Map -> Environment Reference Sheet -> Scene Creator -> Timeline Generator
```

### Five amendments incorporated before implementation
1. **Atlas order corrected** - Atlas Shot is an INPUT to Spatial Map, not an output.
2. **ERS composite is deterministic** - Image Generator creates only Master/N/E/S/W views; Adept UI programmatically composes the final ERS sheet in code. No LLM-generated layout/typography.
3. **Robust @/# syntax** - regexes support real-world names/tags (`@Anga'q'uay`, `#coffee-cup`); UI pickers preferred; tags resolve to stable IDs.
4. **Relative orientation** - ERS directional views (N/E/S/W) are scene-relative; "Atlas North" = top edge of Atlas Shot, not geographic north.
5. **Spatial Authority Law** - Spatial Map coordinates are authoritative; generated imagery cannot silently update spatial data.

### Contracts frozen (in `studio-api/app/spatial_map/ers_contracts.py` + `schemas.py`)
- `SpatialPlacement` extended: `gridRow`, `gridColumn`, `slotIndex`, `colorKey`, `miniPrompt`, `tag` (10x10 grid V1)
- `EnvironmentReferencePackage`: id, project_id, scene_layout_id, atlas_asset_id, master_environment_asset_id, placements, style_context, orientation="atlas-north-up", directional_assets{N,E,S,W}, ers_composite_asset_id, metadata
- `ShotRequest`: index, raw_text, character_ids, prop_ids, framing, angle, orientation, additional_instructions
- `SceneGenerationBatch`: id, project_id, ers_package_id, shot_requests, output_count, result_asset_ids, collection_id, created_at, updated_at

### Frontend type safety fix
TypeScript's problematic behavior with array overrides in intersections required explicit `Omit` + `&` for `SpatialCharacterPlacement`, `SpatialPropPlacement`, and `SpatialMapDocument` in `SpatialMap/types.ts`:
```typescript
export type SpatialCharacterPlacement = Omit<_SpatialCharacterPlacement, keyof SpatialPlacementGridExtension> & SpatialPlacementGridExtension;
export type SpatialMapDocument = Omit<_SpatialMapDocument, "characters" | "props"> & {
  characters: SpatialCharacterPlacement[];
  props: SpatialPropPlacement[];
};
```
