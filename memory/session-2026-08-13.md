## 1. Objective

Refine the Co-Director Library so that selection and bulk deletion work for every deletable media type (image, video, audio, document) and keep the Library toolbar sticky while scrolling.

## 2. Implementation

### Frontend changes
**`studio-web/src/components/CoDirector/library/LibraryMediaGrid.tsx`**
- Removed the `isImageAsset(asset)` gate from card click, checkbox visibility, `is-selectable` class, and Select All scope.
- Selection now applies to all rendered cards: images, videos, audio, and documents.
- Confirmation dialog text changed from "image" to "asset".
- Removed an accidental duplicate `<CardMeta>` in the audio card block.
- Removed dead `duration` state and unused `formatDuration` helper.

**`studio-web/src/components/CoDirector/library/libraryMediaGrid.css`**
- `.library-media-grid__toolbar` now uses `position: sticky; top: 0; z-index: 10`.
- Added solid surface background (`var(--codirector-surface, #141a1f)`) and a subtle bottom border so the toolbar does not visually bleed over cards during scroll.

### Test changes
**`tests/e2e/library-checkbox-certification.spec.ts`**
- Rewritten for all-media coverage: image, video, audio, document.
- Uses sequentially uploaded fixtures to avoid backend connection-pool races.
- Adds `IMAGE_COUNT` and `TOTAL_ASSETS` constants for deterministic count assertions.
- Verifies:
  - mixed-media selection (one of each type)
  - filter-scoped Select All (Images, Video, Audio, Documents)
  - Clear Selection toggle
  - sticky toolbar remains visible after scrolling the library
  - mixed-media bulk delete confirmation
  - persistence after reload

**`tests/e2e/fixtures/codirector-prebeta/cert-video.mp4`**
- New tiny 1-second 320x240 MP4 fixture generated with FFmpeg for deterministic video upload.
