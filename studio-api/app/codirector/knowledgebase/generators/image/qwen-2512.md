# Qwen Image 2512

## Purpose

Local prompt-faithful stills on Image Runtime.

## Identity

Adept row `qwen-image-2512-local`. Not Qwen Edit 2509. Not GPT Image 2.

## Supported modes

- Text-to-image.
- Character Profile Guided stills.
- Image Generator production stills.
- Reference / light edit when Adept wires that Qwen 2512 path.

## Unsupported modes

- Environment Reference Sheets (GPT Image 2 only via Environment Creator Express).
- Standing in when GPT Image 2 REQUIRES SETUP.
- Timeline video.
- Scene Creator Mini as the home for this engine in v1.1 (Mini is not the active still room).

## Inputs

Text prompt, optional character profile, optional Image Generator references (`@` `%` `#` `~`).

## Reference semantics

Approved ERS / `#Environment` is the place lock when bound. A CRS is a person, not the room.

## Prompting semantics

Write concrete nouns. Do not attach ERS layout exemplars as if this were GPT Image 2.

## Strengths

Prompt following. Strong local default for Image Generator and many character jobs.

## Weaknesses

Not the ERS engine. Not a video generator.

## Output contract

Stills in Library. Provenance should read Local — Qwen Image 2512 plus the real mode (Profile Guided, Image Generator, and so on).

## Adept integration

Character Creator, Image Generator. Never Environment Creator ERS / Spatial Map ERS.

## Runtime semantics

READY when Image Runtime has Qwen 2512. Otherwise NOT INSTALLED or REQUIRES SETUP.

## Selection guidance

Pick Qwen 2512 for local stills in Image Generator. If the creator asked for an ERS, switch the job to GPT Image 2 via Environment Creator Express — do not run Qwen.

## Terminology disambiguation

"Qwen" in Adept stills usually means 2512. Edit jobs may mean `qwen-edit-2509`. Never "Qwen ERS."

## What Co-Director may execute

Stills jobs that list this engine.

## What Co-Director must never claim

That Qwen can back up ERS.

## Upstream vs Adept

Upstream Qwen can do many demos. Adept only promises the wired stills modes above.

## Persistence

Library on this project.

## Relationships

- Edit sibling: `qwen-edit-2509`
- ERS: `ers-law`
- Image Generator: `image-generation`
