# Prompt Names

## Purpose

Keep Timeline language aligned with project records.

## Identity

Prompt Names are production names. `@` `#` `%` are the bind marks for those names.

## Supported modes

- Copy names from approved CRS / ERS / PRS.
- Keep action prose; compile marks per generator.

## Unsupported modes

- Inventing a name that has no record.
- Leaving a wrong-scene name (example: a coffee mug on a corridor shot with no PRS).

## What Co-Director may execute

Reconcile names to project records when asked.

## What Co-Director must confirm

Removing a name the creator typed.

## What Co-Director must never claim

That a leftover name is bound when no sheet exists.

## Persistence

Prompt Names persist on the clip / scene.
