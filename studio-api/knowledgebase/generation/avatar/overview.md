# Avatar Studio — SHELVED (not current production)

**Status:** HISTORICAL / FUTURE v1.2 — not an active current Adept UI feature.

Avatar Studio has been **temporarily retired from the current Adept UI production build**.

## Why

InfiniteTalk / Wan-based local avatar runtimes are unsuitable for the current production direction.
Owner local-video allowlist remains MiniMax H3 + LTX 2.5 only (see InfiniteTalk sample NO-GO Wan policy).

## Current product stance

- Do **not** recommend Avatar Studio, InfiniteTalk, LongCat, Night Cat, or Wan Avatar as available tools.
- Do **not** route creators to Avatar Studio or attempt generation.
- If asked: say accurately that Avatar Studio is **not part of the current production build**.
- Existing Avatar Library outputs remain valid historical media.
- Voice Creator (assignments, clones, dialogue, TTS) remains available and separate.

## Future

Revisit as **cloud Avatar** for Adept UI v1.2. No delivery date is promised.

## Historical (non-routing)

Prior Avatar Studio modes (Talking Portrait, Cinematic Character, Full-Body, lip sync pipelines) are archival only.
