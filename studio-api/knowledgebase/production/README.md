# Production knowledgebase

Stubs for Editor / assembly / sound workflows. Generation KB remains under `knowledgebase/generation/`.

**Principle:** Director creates the shots. Editor creates the film.

## Folders

| Path | Focus |
|------|--------|
| `editing/` | Assembly, rough cut, non-destructive versioning |
| `sound_design/` | Audio intent → SFX / ambience / music beds |
| `pacing/` | Duration, rhythm, trim decisions |
| `continuity/` | Screen direction, matches, editorial handoff to Director |
| `dialogue_editing/` | Dialogue track placement and lip-sync awareness |
| `final_export/` | Master / approved export checklist (stub) |

Co-Director retrieves these when task is `editor`, `assemble`, or `mix`.
