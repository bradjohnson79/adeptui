## What this does

The model menu is a real choice. It decides which engine receives the shot and which controls you get.

## Local video

When installed, the local video engines are:

- **MiniMax H3**
- **LTX 2.5**
- **Hunyuan 1.5 Distilled**

They are different models. A result from one is not a stand-in for the other. If the model is not installed, Setup is where that gap shows up. Do not expect another local model to run under the first model's name.

## Hosted video

Hosted clips go through fal.ai when that connection is configured. The hosted set used with Adept UI is Seedance 2.0, Seedance 2.5, Kling 2.5 Turbo Pro, Kling 3.0, Veo 3.1, Runway Gen-3 Turbo, Flux 3.0, Happy Horse 1.0, and Google Gemini Omni.

A hosted job sends the provider what that model requires. Your project still stores the clip that comes back.

## How to choose

Use local when the model is installed and you want the shot to run on your machine. Use hosted when you want that provider's model and the connection is ready. Choose again for the next shot if you need a different engine. The previous shot does not switch itself.

## What this page will not claim

It will not rank the models, promise a resolution, or quote a price. Duration, resolution, and reference support belong to the model you selected. If a published limit is not in front of you in the studio, do not take one from memory.

## Technical notes

Substitution is a defect. If a job completes on a different model than the one you chose, treat the result as wrong and keep the evidence. Do not approve it as if it were the requested engine.
