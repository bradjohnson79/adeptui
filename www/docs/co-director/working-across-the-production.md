## What this does

One conversation can follow a shot from a plan to a cut. The rooms stay in charge of their own files. Co-Director is how you carry the intention across them.

## A practical pass

1. With the project open, describe the scene in Co-Director: who is there, what the shot has to do, and what must not change.
2. Build or adjust the character and references in Character Creator if identity is still soft.
3. Plan the frame in Storyboard Studio when you need to see composition before video.
4. Generate with the model you chose. Say the model by name if the choice matters. Do not ask for "whatever is fastest" if you need a specific engine.
5. Review the clip on the Timeline. Ask Co-Director about the cut only after the clip is actually there.
6. Send the shot you accept to MAGI for grade, scale, overlays, or export.

## What to expect

Co-Director can help you notice a missing reference or a shot that does not continue. It does not place the clip for you unless that action is one you confirm and the Timeline shows afterward.

## Technical notes

Production context is project-scoped. Another project's characters are not silently available. A character marked global is still edited from the project that created it.
