## What it can do

- Talk about the open project's characters, scenes, and next steps
- Help you continue a project you already started
- Point you at Timeline review, asset generation, storyboard, voice, and MAGI
- Keep the conversation attached to this film instead of a blank chat

## What it cannot do

- Pretend a generation finished when no result is in the library
- Silently switch MiniMax H3, LTX 2.5, or a hosted model for a different one
- Turn a casual sentence into canonical character or story data without an authorized save
- Restart an abandoned render just because you opened the project or the Timeline
- See an image it was not actually given. If an attached image cannot be read, the honest result is the reason, not a guess

## Why the limits matter

A film timeline is evidence. If Co-Director says a shot is done and Timeline does not show it, Timeline is right. Go look. Then ask again with the real state.

## Troubleshooting

If Co-Director seems to be answering a different film, confirm the open project name before you continue. If it cannot use production tools, you may not have a project open. If a reply describes a result you cannot find, do not generate a replacement in a new project. Find the job or the asset in this one, or treat the claim as unverified.
