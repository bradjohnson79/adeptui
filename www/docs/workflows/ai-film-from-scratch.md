## What this does

This is one honest path from nothing to a shot you can export. Skip a step only when you already have that piece. Do not skip the project.

## The path

1. Create one project and name it for the film.
2. Create the characters who have to stay recognizable. Save references in this library.
3. If the place or a prop matters, build an environment or prop reference. That is Environment Creator or Prop Creator, not SceneCraft.
4. Board the shot in Storyboard Studio at 16:9 or 9:16. Place frames from the library.
5. Generate any stills you still need with an image model you select.
6. Generate the clip with MiniMax H3, LTX 2.5, or a hosted model you select. Attach the character as a character reference if that model accepts it.
7. Place the clip on the Timeline. Continue only if the next beat is the same shot moving forward.
8. Retake if the performance is wrong. Do not grade a clip you already know you will replace.
9. Send the accepted shot to MAGI. Grade, add overlays if you need them, upscale only when you need a larger file and the GPU path is available, then export.

## What to expect

You end with an export of a shot that exists on the Timeline, in a project you can reopen. You do not end with a guarantee that the model matched every reference. Watch the frames.

## Where people lose the film

They generate the clip in a second project, then cannot find the character. They continue a shot that has no last frame. They open MAGI before they have a clip they accept. Stay in the project and finish the step you are on.
