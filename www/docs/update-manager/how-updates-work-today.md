## What this does

This page records the update behavior that is actually public. It is short because the release channel is not published.

## What you can do now

There is no installer file and no update feed linked from this documentation. Do not follow a third-party "updater" for Adept UI. When a desktop release is published, its install and update steps will be added here.

## Projects during a future update

An update, when one exists, is an application change. It is not a reason to create a new project or to copy a library by hand into a second film. Keep working in the project you already have. Reopen it after the application update and confirm the scenes are still there.

## What is not documented

This site does not publish update channels, a rollback button, or a version number for you to type in. Those would be guesses.

> Note: If you are looking for a channel list, it is intentionally not published. Draft notes about channels are not part of the public docs.
