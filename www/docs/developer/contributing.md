## What this does

Contributing means working on the application itself: source, issues, and changes. That work belongs on the public repository. Learning how to make a film stays in this documentation.

## Why the two places stay separate

A creator installing Adept UI should use the website download when an installer is published. They should not have to read a repository README to open a project, generate a shot, or finish it in MAGI. A developer who wants the source uses GitHub.

## What the repository is for

- Source code
- Issues and development discussion
- Contributions

GitHub releases are not the current installer. No release is published there yet. Desktop installers will be announced with the product release, on the website download, not as a substitute for the studio.

## What to expect

The repository is public for transparency, development, and community contribution. That is not an open-source license, and it is not permission to fork, rebrand, or redistribute Adept UI. Adept UI 1.1 is free AI filmmaking software built around an open AI ecosystem. A final Adept UI License is not published yet.

## Technical notes

The repository linked from this page is the one this project publishes. Article badges point only at that configured destination. They do not accept a pasted URL inside the article, so a guide cannot silently send you to a different account.

If you are changing the product, start from the architecture overview for the public shape of the system, then use the repository for the code. Do not put credentials, tokens, or private paths into an issue.
