## What this does

This is the model map, not a ranking. Use it to see which family a control is talking about.

## Image

Local stills, when those models are installed, include Illustrious XL, Qwen-Image, Z-Image, and Flux.

Hosted stills can include Flux, Krea 2, and other image models you configure in Setup. The Setup list is the list that matters on your machine.

## Video

Local video, when installed, is MiniMax H3, LTX 2.5, and Hunyuan 1.5 Distilled.

Hosted video through fal.ai is Seedance 2.0, Seedance 2.5, Kling 2.5 Turbo Pro, Kling 3.0, Veo 3.1, Runway Gen-3 Turbo, Flux 3.0, Happy Horse 1.0, and Google Gemini Omni.

## What the list does not mean

A name on this page does not mean the files are on your disk. Installation state lives in Adept Setup. A name also does not mean every model accepts the same duration, resolution, or reference type.

WAN is not a current video model in Adept UI. If you remember it from older material, do not select toward it. It is not one of the local video engines.

## Technical notes

Capability metadata decides which controls appear. A text-only path and a reference path are different. The interface should follow the model, not the other way around.
