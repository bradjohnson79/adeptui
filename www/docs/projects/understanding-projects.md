## What this does

The project is the unit of production. When it is open, Character Creator, Storyboard, generation, Timeline, and MAGI read and write that film.

## How to think about organization

Use separate projects for separate films. Inside a project, use scenes for sequences and the library for media. Characters belong to the project that created them. A global character is still edited from that home project.

## Continuity inside a project

References, approved voices, and placed shots survive because they are saved with the project. Reload the project when you want to confirm a save. If the asset is gone after a reload, the save did not hold. Generate again only after you know the first result is actually missing.

## Large productions

A long film is still one project unless you deliberately split deliveries into separate films. Splitting every scene into a project breaks character reuse and makes Co-Director's context the size of a single scene with no neighbors.

## Recovery

Reopen the project before you assume it is lost. Abandoned renders are not resumed, but finished assets remain. This page does not describe a file-level backup format, because that procedure is not published here. Do not invent a manual copy step as if it were the product's archive button.

## What to expect

Creating a character or an image does not create a project. If the studio offers a new project dialog, that is a different action from Generate.
