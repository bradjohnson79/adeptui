## What this does

First launch is the moment the desktop app opens before any film exists. The useful outcome is a ready studio and one named project.

## What to do

1. Open Adept UI and let the studio come up. You do not launch the generation runtime yourself.
2. Open Adept Setup if you need to see component readiness. Guided is the shorter path. Manual shows the full catalog.
3. Create one project for the film you are starting.
4. Only then generate a still, a voice, or a clip.

## What to expect

The application can open before every optional model is installed. A missing local model means that model is unavailable. It does not mean the project system is broken.

## Common mistakes

Generating during a half-finished setup and then starting a new project to "try again." Finish or repair setup in the same studio, and keep the project.
