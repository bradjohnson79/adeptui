## What this does

Installation is how the desktop application arrives on a workstation. The platforms are Windows, macOS, and Linux. Phones and tablets are not the production app.

## What is published today

The website download has the Beta installers: a Windows setup, a macOS disk image, and a Linux package chooser. Ubuntu and Debian-based systems use the .deb package. Fedora and compatible RPM-based systems use the .rpm package. A portable AppImage is also available. On Linux, choose the package. The download does not install by itself. Open the downloaded package and use the graphical installer. Adept UI then appears in the application menu.

## When you have the installer

1. Use the download for the desktop you are actually on.
2. Run that platform's installer. Do not rename it into a different operating system.
3. Open Adept UI from the desktop application. You should not need a separate launcher for the film.
4. On first launch, Adept Setup is where readiness is checked. Model files, if you want local generation, are a setup step after the application itself is installed.

## Installing without local models

You can plan to use hosted generators only. Local video and image models are optional until you want them. Hosted generation still needs the provider connection configured in Setup. It does not remove the need for the desktop application.

## What to expect

A successful install opens the studio. It does not by itself download every model. An incomplete model setup is repaired in Adept Setup, not by installing the application a second time.

## Common mistakes

Treating a model file as the application, or treating the website as the studio. The public site explains the product. The film is made in the desktop app.
