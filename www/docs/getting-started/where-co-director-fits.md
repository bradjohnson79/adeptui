## What this does

Co-Director is how you talk about the film you already have open. You can ask it to continue the project, look at the Timeline, or help generate assets. The rooms still do the production work.

## Why it is not a separate app

A general chat does not know which character is in the scene. Co-Director is scoped to the open project so the conversation has a production to refer to. If no project is open, those production tools are limited.

## How to use it

1. Open the project you mean.
2. Open Co-Director chat or a quick action such as Continue Project.
3. Talk about a scene, a character, or a shot in that project.
4. When the next step is a generation or an edit, do that step in the room that owns it, with the model you intend.

## What to expect

Conversation is not the same thing as saved project data. A suggestion becomes production truth when you save or approve it through the normal project path.

> Warning: Do not assume Co-Director has changed a character, a model, or a Timeline shot unless you can see that change in the project after you reopen it.
