## What this does

This is the map, not a generation tutorial. Five minutes is enough to see which room does which job so you do not generate a clip before the shot has a place to live.

## A pass through the studio

1. Open a project, or create one and stay in it.
2. Look at Character Creator if the shot depends on a person. Identity, references, and voice belong to that character.
3. Open Storyboard Studio if you want to see the frame before you spend a video generation.
4. Image Generation is for stills and reference art. Video generation is a separate choice of model and shot.
5. Voice Studio is the character's voice. Audio Studio is music, ambience, and Foley.
6. Timeline is where shots become a scene. MAGI is where a selected shot is graded, scaled, composed, and prepared for delivery.
7. Co-Director is available from the project. It is a guide across those rooms, not a second library.

## What to expect

You should be able to name the room for the job you actually want. A still is not a Timeline shot. A storyboard panel is not a finished video. A voice approval is not an audio bed.

## Common mistakes

Generating first and organizing later. The library can hold the result, but the shot is easier to continue when it already belongs to a scene and a character.
