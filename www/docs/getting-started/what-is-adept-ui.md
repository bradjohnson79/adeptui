## What this does

Adept UI is the place you make the film. It holds the project, the characters, the boards, the generations, the scene, and the finish. The image, video, and voice models are engines you choose. Adept UI is not itself a video model.

## Why you would use it

A shot usually starts as an idea, becomes a reference, then a clip, then a cut, then a grade. If each of those steps lives in a different app, the character and the project get lost between them. Adept UI keeps that chain in the open project.

## How it works

The production menu groups the work the way a film is made:

- Create and pre-production: script, characters, environments, props, storyboard
- Creative studios: image generation, voice, audio
- Assembly and finish: Timeline, MAGI
- The project library: the stills, clips, and audio that belong to this film

Co-Director sits across that work. It can talk about the open project. It does not replace the rooms where you actually generate or edit.

## What to expect

You open one project and stay there. Creating a character, a still, or a clip does not open a second project. Generated media lands in that project's library.

> Note: Desktop installers for Windows, macOS, and Linux are on the website download. Adept UI 1.1 is free local software. Third-party models and APIs keep their own costs, and a future Adept Cloud may have its own charges.

## Technical notes

Adept UI routes a generation to the model you selected. It does not silently swap in a different model because another one is easier to run. Local engines run on your machine when they are installed. Hosted engines run through a configured provider connection.

Adept UI 1.1 is free AI filmmaking software built around an open AI ecosystem. It is not open-source software. Open-weight models you run locally are not a license for the Adept UI application.

## Related confusion

Adept UI is not a chatbot with a video button, and it is not a single foundation model. If a guide talks about MiniMax H3, LTX 2.5, Seedance, Kling, Veo, or Runway, those are generators Adept UI can run. The product around them is the project, the references, the Timeline, and the finish.
