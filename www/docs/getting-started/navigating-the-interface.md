## What this does

The interface is the production menu plus the room you opened. You move between rooms without leaving the project.

## The rooms you will actually use

| Room | What you do there |
| --- | --- |
| Character Creator | Identity, references, appearance, voice |
| Storyboard Studio | Plan frames before a video generation |
| Image Generation | Stills and reference art |
| Voice Studio | A character's spoken performance |
| Audio Studio | Music, ambience, and Foley |
| Environment Creator | Environment reference work |
| Prop Creator | Prop reference work |
| Timeline | Sequence, continue, and retake shots |
| MAGI | Grade, upscale, compose, export |
| Library | Media that belongs to this project |
| Adept Setup | Readiness and component preparation |

Scriptwriter is the writing room when you are developing the script in the project.

## What to expect

The menu groups rooms as Create, Pre-Production, Creative Studios, and Post. Recent projects are a way back to a film, not a new film.

## Technical notes

Each room is a workspace inside the same studio. Setup is the workspace named Setup. It is not a separate installer brand.
