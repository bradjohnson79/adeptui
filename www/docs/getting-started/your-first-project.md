## What this does

A project is the film's folder in the studio. Scenes, characters, and generated assets belong to the project that is open.

## Why you would use one project

If each still opens a new project, you cannot build a scene. Character work, storyboard panels, and Timeline shots need the same library.

## How to start

1. Create a project with a name you will still recognize later. Use the film's name, not "test" plus a number, unless you are truly experimenting.
2. Stay in that project while you create a character or generate an image.
3. Confirm new media shows up in that project's library.
4. When you leave and come back, reopen the same project. Saved work should still be there.

## What to expect

Co-Director's production tools are limited until a project is open. Without a project, there is no production for it to read.

## Common mistakes

Starting a second project because a generation failed. The failure belongs in the original project's history. A new project does not repair the shot.

> Tip: Name the project for the production. You can have more than one film. You should not have one project per frame.
