## What this does

This page exists so you do not look for a 3D room that is not in the current product. SceneCraft is the name for spatial reconstruction work planned for a later release.

## What to use now

- **Environment Creator** for environment reference sheets and the place the shot happens
- **Prop Creator** for prop reference sheets
- **Storyboard Studio** and **Image Generation** for frames of those places and objects
- **Timeline** for the shot itself

An environment reference sheet is an ERS. A prop reference sheet is a PRS. They are 2D production references in the current studio, not a SceneCraft scene.

## What not to expect

No current menu should be treated as SceneCraft production. There is no published 3D layout workflow, character blocking tool, or spatial export in this documentation, because that functionality is not in the current set.

## Technical notes

The implementation is preserved for later work. Preservation is not the same as a creator destination. If a guide elsewhere describes SceneCraft as a step in your film today, that guide is ahead of the product.
