## What this does

Setup Mode changes how much of the catalog you see. It does not change which project is open.

## Which mode to use

Use **Guided** when you want the studio to keep Prepare My Studio in front and you are not hunting a single component.

Use **AI-Guided** when you want a recommended provider path and a walkthrough of install, calibration, and certification.

Use **Manual** when you need the full list, advanced actions, or Source Manager. Manual is the right mode for a specific missing model, not a more "real" install.

## What to expect

Switching to Manual does not uninstall Guided, and it does not start a generation. After you prepare a component, use the studio's verify action and read the result.

## Common mistakes

Entering a folder path from memory. If Setup offers a location, use that suggestion unless you are deliberately pointing at a directory you maintain. A wrong folder looks like a missing model later.

## Technical notes

AI-Guided compares certified options. It should not be read as permission for Adept UI to swap a model during a shot. Model choice at generation time is still explicit.
